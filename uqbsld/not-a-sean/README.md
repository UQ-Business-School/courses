# Not-a-Sean

The bits and pieces: everything Sean built or set up for the UQ Business School learning design team, on one page, with what it is, who has access, and who to ask while he is on leave.

Lives at `uqbsld/not-a-sean/` in the UQ-Business-School/courses repo, so it serves at https://uq-business-school.github.io/courses/uqbsld/not-a-sean/ and mirrors to https://teach.business.uq.edu.au/ld/uqbsld/not-a-sean/

## What is in here

| Path | What |
|---|---|
| `index.html` | The page. Built on the teach.business HTML standard (links `uqbs.css` and `uqbs.js` from teach.business.uq.edu.au). |
| `drop/` | Drop, the in-house Rise replacement, as a static page. Publishing to GitHub and sign-in were removed in this version; see the note on the page. The file is the built bundle, not source. |
| `duck/` | The frozen Who's That Duck team wall, the make-your-own kit and the template image. |
| `skills/` | The six UQ Claude skills as `.skill` downloads. |
| `bookmarklets/` | Project Spider: Blackboard Map, the content inventory (v7) and Instructor to TA. Source and tests live in the Project Spider folder in Claude Projects. |
| `notabot/` | The 2026 AALL presentation as a PDF. |

## Editing

It is one HTML file. Edit `index.html`, push to `main`, GitHub Pages redeploys in about a minute. Keep to the components in the teach.business standard so it stays on brand.
