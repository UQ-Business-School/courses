Project Spider, stage 1

Blackboard Map

Map every item in a set of Blackboard courses, down to what is embedded inside each document.

What this is

A button that walks through the courses you pick and writes down everything in them.

For every folder, document, file and tool link it records the folder path, the week, whether students can see it, and a link that opens it. It also looks inside each document and lists what is embedded there: files, HTML blocks, H5P, Echo360 and videos.

It is the first stage of Project Spider. The manifest it saves is the list the later stages download from, so check the course map against Blackboard before going any further.

Before you worry about running a script

  • It only reads. Nothing in it writes, edits, hides or deletes.
  • It runs in your browser, signed in as you, and only ever talks to learn.uq.edu.au.
  • Nothing is sent anywhere. The three files are built on your own machine and saved to your Downloads folder.
  • No AI is involved in running it, and no outside code is loaded.
  • It goes slowly on purpose: one course at a time, with a short pause before every request.
Easiest way

AUse the button

Set it up once and it becomes a button you press.

Drag the yellow bar below onto your bookmarks bar. If you cannot see your bookmarks bar, press Ctrl Shift B to show it.

Blackboard Map

Drag it up to the bar. Clicking it here does nothing.

Then open Blackboard, sign in, and click Blackboard Map in your bookmarks bar. A small green panel opens in the top right corner of the page.

If no panel appears within a few seconds, your browser has blocked the bookmarklet. Use Option B instead.

If the button is not an option

BPaste it into the console

The console is a panel built into your browser where you can run a piece of code.

  1. Sign in to Blackboard in Chrome or Edge. Any Blackboard page will do.
  2. Press F12 and click the Console tab.
  3. The first time only, Chrome will ask you to type allow pasting and press enter before it lets you paste.
  4. Press the copy button below, click into the console, paste, and press enter.

Choosing what to map

A teaching period, then a list of course codes.

The panel opens on the last teaching period that has finished, because that is the one worth mapping. The current semester is still being built and next semester's shells are empty.

Type or paste course codes into the box, separated by spaces or commas. The BBusMan core button fills in the eight core courses for the pilot. Leave the box empty to map every course you can see in that period.

If a code does not turn up in that period, the panel tells you before you press Run. Each course takes a few seconds, so the eight core courses are usually done in under a minute.

What you get

Three files, saved when you press the buttons in the panel.

A course map

Each course as a tree, folder by folder, with what is inside every document. Open it next to Blackboard and check nothing is missing.

A manifest

The same list as JSON, which is what Spider's next stage reads. Keep it with the course folders.

A spreadsheet

One row per item, for Excel. The columns worth knowing are below.

ColumnWhat it tells you
offeringThe full course code. BISM1201_7620_... is BISM1201 in Semester 1, 2026
kindFolder, module, document, file, tool, web link or assessment. Things embedded in a document show as embedded file, html block, h5p, echo360, or video or embed
detailFor tools, which tool it is. For embeds, the file type or the kind of H5P activity
pathThe folder path down to the item
weekThe week number, taken from the nearest folder or title that names one
studentsSeeYes, No or Conditional. No if the item or any folder above it is hidden
fileNameThe stored filename, for files and embedded files
embedOfFor embedded things, the document they sit in
linkOpens the item, or the document an embed sits in

If something goes wrong

It says I am not allowed to paste

Chrome blocks pasting into the console until you tell it once that you understand. Type allow pasting into the console, press enter, then paste again.

I clicked the bookmark and nothing happened

The panel takes a moment because it reads your course list first. If nothing shows up after a few seconds, your browser or a policy has blocked the bookmarklet, and Option B will still work.

A course code says not found

That course has no shell in the period you picked, or you are not enrolled in it as staff. Try another period, or check the code.

A course could not be read

The panel lists it when the run finishes and the manifest records the reason. Usually it is a course with unusual permissions. Everything else in the run is still fine.

Nothing downloaded

The files only save when you press the buttons in the panel. If you pressed them and nothing arrived, check for a blocked download icon in the address bar.
